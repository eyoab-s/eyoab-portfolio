# AGENTS.md — Eyoab Seifu Portfolio

## Project Overview
A personal portfolio website for Eyoab Seifu, a Software Engineering student and developer based in Addis Ababa, Ethiopia.

The website should showcase projects, technical capabilities, professional background, and contact information to potential employers, recruiters, and freelance clients.

## Technology Stack
- Next.js (App Router)
- React
- TypeScript
- Tailwind CSS
- Motion (`motion/react`)
- Lucide React

## Design Direction

The visual identity is inspired by the design philosophy of Nothing:
- Minimal, industrial, precise, and editorial.
- Monochromatic foundation with a restrained lime accent.
- Generous whitespace and strong typographic hierarchy.
- Thin borders, structured grids, and technical details.
- A custom dot-matrix system as the portfolio's signature identity.

This is an original identity. Do not directly copy Nothing's branding, logo, or website.

### Color Palette
- Paper: #F2F2F0
- Ink: #151515
- Graphite: #888888
- Lime: #D9FF38

### Typography
- Display: Space Grotesk
- Technical labels: DM Mono
- Large editorial headlines.
- Uppercase technical metadata.

## Design Principles
1. Prioritize visual quality and intentional composition.
2. Avoid generic developer portfolio templates.
3. Avoid excessive gradients, glassmorphism, glowing effects, and unnecessary rounded cards.
4. Use lime selectively for emphasis and interaction.
5. Use subtle, purposeful animations.
6. Maintain excellent responsive behavior.
7. Respect reduced-motion preferences.
8. Keep the interface accessible and readable.

## Development Guidelines
- Use TypeScript throughout.
- Prefer reusable, well-structured components.
- Keep project data separate from presentation components.
- Use semantic HTML.
- Avoid unnecessary dependencies.
- Keep components focused and maintainable.
- Do not introduce placeholder information as verified personal facts.
- Ensure all external links work and use appropriate security attributes.
- Test responsive layouts before considering a feature complete.
